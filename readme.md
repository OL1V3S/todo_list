# To-Do List

## Demo

Hosted at https://ol1v3s.github.io/todo_list/

## About

A responsive to-do list web app built with HTML, CSS, and JavaScript.

## Features

- Add, delete, and mark tasks as completed.
- Drag and drop tasks to reorganize them.
- Filter tasks by all, active, or completed.
- Track the number of remaining tasks and clear completed tasks.
- Tasks persist using localStorage.
- Hosted on GitHub Pages.
